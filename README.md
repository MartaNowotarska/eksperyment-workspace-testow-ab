# Eksperyment — workspace testów A/B

Publiczna, samodzielna strona demonstracyjna dla product builderów. Aplikacja pomaga uporządkować kontekst, hipotezę, setup, wyniki i decyzję dotyczącą testu A/B.

## Dane i prywatność

- Strona nie wymaga konta i nie ma własnego serwera, bazy danych ani integracji analitycznej.
- Wpisany tekst i opcjonalny plik .txt są odczytywane w bieżącej karcie przeglądarki. Kod aplikacji nie wysyła ich na serwer ani nie zapisuje trwale.
- Eksporty są pobierane lokalnie przez użytkownika. Odświeżenie lub zamknięcie karty usuwa niezapisany draft.
- Do czasu ustalenia zasad firmowych używaj danych przykładowych. Nie wklejaj danych poufnych ani osobowych.

## Granice działania

To prototyp do przygotowywania materiałów. Nie tworzy eksperymentów w TestDrive, nie zapisuje ich w Second Brain, nie łączy się z analityką i nie zmienia produkcji. Proste porównanie wyników nie zastępuje analizy statystycznej.

Strona jest zbudowana jako pojedynczy plik index.html; biblioteki wbudowane w plik opisano w THIRD_PARTY_NOTICES.md.
